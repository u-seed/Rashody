# 💰 Семейные финансы

Приложение раскладывает выписки Kaspi Gold и Halyk по категориям и месяцам.

## Как обновлять (раз в 1–6 месяцев)
1. Положите свежие PDF-выписки в папку `input/` (Kaspi Gold и Halyk, свои и жены; пересечение периодов — не проблема, дубли убираются).
2. `pip install -r requirements.txt` (один раз; нужен также `pdftotext` из poppler)
3. `python scripts/build.py` — спросит пароль (или `APP_PASSWORD=... python scripts/build.py`)
4. `git add docs && git commit -m "update" && git push`
5. GitHub → Settings → Pages → Deploy from branch → `main` / `docs`.

Скрипт проверяет, что суммы по разобранным операциям сходятся с итогами банка (✓ в консоли).

## Приватность
- PDF не попадают в git (`.gitignore`). В репозиторий уходит только `docs/data.enc.json` — зашифрован AES-256-GCM, расшифровывается в браузере по паролю. Накопленная история хранится в нём же, старые PDF хранить не нужно.
- Не теряйте пароль: восстановить данные без него нельзя. Для локального просмотра без шифрования: `python scripts/build.py --plain`, затем `cd docs && python -m http.server`.

## Настройка категорий
`config/categories.json`: добавляйте слова магазинов в `merchant_rules` (первое совпадение побеждает) и пересоберите. Блок «Прочие покупки» в консоли показывает, что не распознано.

## Что не считается доходом/расходом
Переводы между своими счетами и членами семьи, депозиты, крупные «Поступления на счёт» (≥1 млн, обычно возврат с депозита). Кредиты получены — отдельно, платежи по кредитам — расход.
